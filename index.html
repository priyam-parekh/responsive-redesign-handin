intro

The Friends of Benson Park website plays an important role in providing information about my local park—including events, community involvement, and more. However, the website has a plethora of accessibility issues that makes it difficult to navigate for all users

This project focuses on improving the usability, accessibility, and design of the website while maintaining the original content and structure

context

The Friends of Benson Park is my hometown's non-profit organization. It aims to conserve the park's history and trails. The website's main purpose is to allow people to get involved and learn more about what the Friends of Benson Park do to keep the park open to all visitors and residents.

problems with the current design

The current website was evaluated using 4 criteria: efficiency, learnability, memorability, and the effectiveness of its conceptual model

Furthermore, the site was analyzed with the WebAIM WAVE tool to detect accessibility issues pertaining to the text and backround contrast, voice-over capabilities, and errors

Issue Category Usability Issues Explanation
Efficiency
  • Unclear hierarchy of buttons
  • Inefficient navigation structure
  • Important information is hidden in sections
  • The "Donate" and "Memberships" buttons (call to action) compete to get the user's attention
    • Users might hesitate about which button to click
  • Users must scroll extensively to find key content like events and trails
  • Donation impact and trail information sections appear far down the page
Learnability
  • Lack of clear visual differentiation between different sections
  • Text readability issues
  • Illegible form fields
  • The site lacks visual distinction between each of the sections
    • Sections like "Family Fun Day Photos" and "Here's What's New" make it difficult for a user to understand the organization
  • The text overlays on the background images ("The Friends of Benson Park", etc.) lack sufficient contrast, making it difficult to read
  • The form fields are difficult to read because of insufficient contrast and text size
Memorability
  • Subpar visual consistency
  • Oversaturated background images
  • Multiple sections on the page use different font sizes and styles, making the site inconsistent
  • The background images are too vibrant, making it overwhelming for the user to navigate the page/remember what section they are on
Conceptual Model
  • Misaligned information priority
  • Unintuitive navigation
  • Unclear and weak visual hierarchy
  • Users would expect nonprofit websites to prominently feature a clear mission, donation details, and their impact on the community. However, on this page, important sections like donations and how to get involved are deeper down the page or are embedded in a small button
  • Users expect navigation to guide them logically through the website's content; however, this website scatters key information throughout the page—forcing the user to scroll through the entire page
  • Websites typically use consistent visual grouping, colors, and other distinctions to allow for clear sections. This website blends together photo galleries, recent news, events, etc. without sufficient visual hierarchy. Also, the saturated images make the website appear more overwhelming

analyzing WebAIM WAVE results

I do agree with a majority of the WebAIM WAVE's analysis of the website's accessibility problems

For instance, I noticed that none of the images have alt-text, which I also discovered when using voice-over on my Mac

Furthermore, there are approximately 15 contrast errors due to the white text on the saturated images, dark gray text on the light gray background, along with the cherry red and white text combination

In terms of both visual and accessibility standards, the Friends of Benson Park website needs a major overhaul to fix the accessibility issues

the redesign

Based on the usability evaluation and accessibility analysis, I created a redesign that addresses these issues while maintaining the website's core functionality
